# 🎯 MockMate – AI-Powered Mock Interview Platform

**MockMate** is an intelligent, full-stack mock interview platform designed to simulate real-time technical and HR interviews with automated scoring and instant actionable feedback.

---

### ✨ Key Features

* **Dynamic AI Interviews:** Simulates realistic technical and behavioral interview scenarios tailored to specific developer roles.
* **Instant Feedback & Scoring:** Real-time analysis of answers with granular metrics, strengths, and areas for improvement.
* **Credit-Based Usage:** Integrated middleware to securely track user sessions and manage interview credits.
* **Modern Analytics Dashboard:** Intuitive UI to track practice history, scores, and overall preparation progress.

---

### 🛠️ Tech Stack

* **Client:** React.js, Tailwind CSS, Lucide Icons
* **Server:** Node.js, Express.js
* **Database:** MongoDB & Mongoose
* **Authentication:** JWT (JSON Web Tokens)
* **AI Engine:** Generative AI API Integration
